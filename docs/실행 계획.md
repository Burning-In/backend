# 실행 계획

> 형식: 폴리아의 미/자/조 — 🎯 미지(만들어내야 하는 것) / 📦 자료(손에 쥔 것) / 🔗 조건(자료와 미지의 배치).
> 미/자/조 아래 궤적(자료가 조건을 지키며 미지로 가는 길)과 💀(놓치기 쉬운 한 방)을 둔다.
> 기준 문서: [서비스 정의.md](서비스%20정의.md) · 근거 상세: [서비스 개선 방안.md](서비스%20개선%20방안.md)

## 전체 미지

🎯 **미지** — "차트를 보고 싶은데 공부해야 되는 사람에게, 추세추종과 평균회귀 기법을 혼합하여 차트를 보여주고, 원한다면 그 방식에 익숙하게 만들어주는 서비스"의 실현  
📦 **자료** — 배치 파이프라인(베이스·VCP·단계·리짐 계산), 인사이트 8종 API, 랭킹 2종, 회고(스냅샷), 차트(박스 포함), 실시간 스트림, 과거 일봉 전체  
🔗 **조건**
- 이 미지는 통째로 만들 수 없고, 여덟 개의 작은 미지(M0~M7)로 나뉜다.
- 작은 미지 하나마다 문장의 네 성분 중 하나를 채운다: 믿을 수 있게(A) / 읽어주고(B) / 기법을 골라(C) / 원하면 익히게(D).
- M6(검증)의 결과가 M7(평균회귀)의 착수 여부를 정한다 — 계획의 유일한 분기점.

#### 자료에서 미지까지 — 실행 순서대로

```text
📦 목업 섞인 화면 ──① M0 목업 정리──→ 숫자 전부가 출처를 가짐 ──────────▶ A 절반
                                          │
📦 인사이트 8종 값 ──② M1 지표 해석──→ 값마다 문장이 나옴 ─────────────▶ B 1/3
                                          │
📦 저항·지지선 ────③ M2 자리 판정──→ 피벗·확장도·리스크 ──────────────▶ B 2/3
                                          │
📦 저장된 단계·VCP ─④ M3 베이스 라벨→ 박스가 읽힘 ────────────────────▶ B 완성 ✓
                                          │   "보여주고"가 "읽어주고"가 됨
📦 지수 일봉 ──────⑤ M4 시장 국면──→ 오늘의 유효 여부 판정 ───────────▶ C 절반
                                          │
📦 기존 회고 ──────⑥ M5 판단 기록──→ 판단이 1초에 남음 ───────────────▶ D 완성 ✓
                                          │   "원한다면"의 길이 열림
📦 과거 일봉 전체 ──⑦ M6 시그널 검증→ 기법의 성적표 ──────────────────▶ A 완성 ✓
                                          │
                              🔗 성적표가 착수 여부를 정한다 (게이트)
                                          ├─ 실패 → 기법 수정 후 M6 재시도
                                          ▼ 통과
📦 시장 판정+리짐 ──⑧ M7 평균회귀──→ 종목마다 맞는 기법으로 읽힘 ──────▶ C 완성 ✓
                                          │   "혼합하여"가 성립
                                          ▼
🎯 네 성분이 모두 채워짐 = 문장의 실현
```

💀 **네 성분 중 하나라도 비면 문장이 통째로 깨진다** — A 없으면 읽어줘도 믿을 이유가 없고, B 없으면 보여주기만 하는 지금 상태고, C 없으면 "혼합"이 거짓말이고, D 없으면 "원한다면"의 길 자체가 없다.

## M0. 목업 정리 — 출처 있는 숫자만 남은 화면

🎯 **미지** — 모든 숫자가 출처를 갖는 화면  
📦 **자료** — 하드코딩된 탭 종목 개수(24/12), 고정 수치를 그리는 메인 카드 3장과 차트 카드, 실데이터가 나오는 랭킹 응답, 기존 인사이트·차트 API  
🔗 **조건**
- 가짜 숫자와 진짜 숫자가 한 화면에 섞여 있고, 사용자에게는 구분 수단이 없다.
- 화면이 믿음을 얻는 것은 가짜가 하나도 남지 않았을 때뿐이다.

#### 자료에서 미지까지

```text
📦 프론트엔드 화면 전체
        │
        ▼
   ① 가짜 목록          하드코딩·목업 수치를 빠짐없이 나열
        │ 🔗 구분 수단이 없으므로 목록이 완전해야 한다
        ├─ 기존 API로 연결 가능 ──→ ② 실데이터 교체
        └─ 연결 불가 ──────────────→ ③ 삭제
        ▼
🎯 어떤 숫자를 가리켜도 "어디서 온 값"이라 답할 수 있는 화면
```

💀 **연결할 수 없는 것은 고치지 말고 지운다** — 가짜 하나가 진짜 전부를 의심받게 한다.

## M1. 지표 해석 — 값이 문장이 되는 카드

🎯 **미지** — 지표 값이 어떤 값이든 그 종목의 지금 상태를 말해주는 한 문장  
📦 **자료** — 인사이트 8종의 값(백분위·배율·정배열 수·단계·리짐), 베이스 설계 의도 문서의 "단계 3+ = 매도 경각심", 거래량의 양날 성질(돌파 순간의 대량 거래와 확장 상태의 대량 거래는 다르다)  
🔗 **조건**
- 값 구간 하나마다 문장 하나가 대응한다.
- 거래량의 문장은 값만으로 정해지지 않고 리짐과 짝지어야 정해진다.
- 문장의 범위는 사실 서술까지다 — 매매 지시("사세요/파세요")는 미지에 포함되지 않는다.

#### 자료에서 미지까지

```text
📦 지표 값 (8종)
        │
        ▼
   ① 구간 매핑 표       카드 8종 × 값 구간 → 문장 (시안 작성 → 확정)
        │ 🔗 값 구간 하나마다 문장 하나
        ▼
   ② 문맥 교차          거래량은 리짐과 짝지어 문장 결정
        │ 🔗 같은 값이라도 리짐이 다르면 다른 문장
        ▼
   ③ 카드 해석문        정의문 아래 값에 따라 바뀌는 한 줄
        │ 🔗 사실 서술까지만
        ▼
🎯 어떤 값이 와도 자연스럽고 정확한 한 문장
```

💀 **단계 3+의 경각심 문구가 설계 문서에만 있고 화면에 없다** — 이 서비스에서 가장 값진 도메인 지식이 사용자에게 전달된 적이 없다.

## M2. 자리 판정 — 자리를 말하는 세 숫자

🎯 **미지** — 진입 기준가, 그로부터 벌어진 거리, 감수해야 할 손실 폭 — "지금 들어가도 되는 자리인가"를 답하는 세 숫자와 그 숫자로 선 목록 순서  
📦 **자료** — 최강 저항선과 상단 경계, 최저 지지선, 현재가, 돌파 준비/성공 랭킹 2종, 실시간 스트림 아이템  
🔗 **조건**
- 진입 기준을 정하는 것은 가장 강한 저항선의 상단이다.
- 준비 목록의 순서를 정하는 것은 종목의 질이 아니라 기준가까지의 거리다.
- REST 목록과 실시간 목록은 같은 값을 보여줘야 한다.

#### 자료에서 미지까지

```text
📦 최강 저항선 ──→ ① 피벗            돌파가 유효해지는 기준가
                        │ 🔗 진입 기준을 정하는 것은 최강 저항선의 상단
📦 현재가 ────────→ ② 확장도          피벗 대비 현재가의 거리 %
📦 최저 지지선 ──→ ③ 리스크          손절선까지의 거리 %
                        │
                        ▼
📦 랭킹 2종 ─────→ ④ 목록 정렬       준비: 피벗 근접순("오늘 지켜볼 순서")
                                     성공: 확장도 표기("이미 늦은 종목")
                        │ 🔗 REST와 스트림은 같은 값
                        ▼
🎯 판정 단어 대신 세 숫자 — "피벗 +13.7%, 손절 -19.6%"
```

💀 **"돌파했다"는 이미 아는 사실이다** — 차트 앞의 진짜 질문은 "얼마나 늦었나"이고, 그게 확장도다.

## M3. 베이스 라벨 — 박스만 보고 읽히는 사이클

🎯 **미지** — 박스만 보고 읽히는 사이클 단계와 응축 상태  
📦 **자료** — 배치가 매일 계산·저장하는 단계·VCP·베이스 성격, 위치와 크기만 전달되는 차트 박스, 기존 지지·저항/이동평균 토글  
🔗 **조건**
- 라벨의 내용은 새 계산이 아니라 이미 저장된 값이다.
- 박스 하나마다 라벨 하나.
- 표시 여부는 사용자 선택(토글)에 달려 있다.

#### 자료에서 미지까지

```text
📦 저장된 단계·VCP·성격
        │ 🔗 새 계산이 아니라 이미 저장된 값
        ▼
   ① 응답 확장          박스 응답에 세 값을 실음
        │ 🔗 박스 하나마다 라벨 하나
        ▼
   ② 박스 라벨          "2단계 · VCP 응축중"
        │ 🔗 표시 여부는 사용자 선택
        ▼
   ③ 라벨 토글          기존 토글과 같은 방식 — 기본값 ON/OFF는 실물 보고 결정 [미결]
        ▼
🎯 차트만 보고 "몇 번째 사이클, 응축 여부"가 읽힘
```

💀 **가장 값진 계산이 API 직전에서 버려지고 있었다** — 이 미지는 만드는 일이 아니라 전달하는 일이다.

## M4. 시장 국면 — 오늘이 이 기법의 계절인지 말하는 첫 줄

🎯 **미지** — 오늘 이 기법이 먹히는 날인지 말해주는 판정 값과 그것이 놓일 첫 줄  
📦 **자료** — 지수 데이터(배치의 KOSPI 수집 경로), 이동평균, "돌파매매는 상승 추세장의 기법"이라는 전제, 판단 기록(M5)의 저장 구조, 기법 선택(M7)의 입력 자리  
🔗 **조건**
- 돌파매매가 유효한 것은 상승 추세장 안에서만이다.
- 이 판정 값은 세 곳에서 같은 값으로 쓰인다: 첫 화면의 배너, 판단 기록(M5), 기법 선택(M7).

#### 자료에서 미지까지

```text
📦 지수 일봉
        │
        ▼
   ① 시장 판정          지수의 MA 위/아래 + 추세 방향 (두세 값이면 충분)
        │ 🔗 같은 값이 세 곳으로 간다
        ├──→ ② 첫 줄 배너         열자마자 "오늘 먹히는 날인가"
        ├──→ ③ 기록 항목          M5의 판단 기록에 포함
        └──→ ④ 선택 기준          M7의 "어느 기법으로 읽나"의 입력
        ▼
🎯 첫 줄에서 오늘의 유효 여부를 알고, 같은 값이 기록과 선택의 기반이 됨
```

💀 **배너 하나로 만들고 끝내면 M7에서 재작업한다** — 이 값은 화면 요소가 아니라 세 곳에 꽂히는 기반이다.

## M5. 판단 기록 — 1초에 남는 판단 (기존 회고의 개편)

🎯 **미지** — 1초에 남는 판단 기록과 거기서 쌓이기 시작하는 데이터  
📦 **자료** — 기존 회고(판단과 글이 한 몸), 판단 3종(매수/매도/관망), 근거 태그 후보(돌파/눌림목/랭킹 보고/뉴스/감), 일봉(경과 수익률 계산 수단), 시장 판정(M4)  
🔗 **조건**
- 기록이 남는 빈도를 정하는 것은 보람이 아니라 비용이다.
- 판단 하나마다 그 시점의 근거(태그)와 시장 상태가 함께 남아야 나중에 분류된다.
- 수익률 한 건은 판단의 채점이 아니다 — 통계가 될 만큼 쌓여야 의미를 갖는다.
- 기록은 옵트인이다 — 기록 안 하는 사용자도 완결된 사용자다.

#### 자료에서 미지까지

```text
📦 기존 회고 (판단+글 한 몸)
        │ 🔗 빈도를 정하는 것은 비용
        ▼
   ① 판단·글 분리       버튼 한 번 = 기록 완결, 글은 선택 (10분 → 1초)
        │ 🔗 판단 하나마다 근거와 시장 상태가 함께
        ▼
   ② 태그·시장 동봉     클릭 두 번으로 분류 가능한 기록
        ▼
   ③ 경과 부착          +5일/+20일/현재 수익률 자동
        │ 🔗 한 건은 채점이 아니다 — 쌓여야 의미
        ▼
🎯 기록이 쌓이기 시작 — 나중의 통계("확장 자리 진입 30건 승률 33%")의 재료
```

💀 **글 쓰는 회고는 아무도 계속하지 않는다** — 기록이 안 남는 건 게으름이 아니라 구조의 문제였다.

## M6. 시그널 검증 — 기법의 성적표 ⚑ 게이트

🎯 **미지** — 이 기법(추세추종 렌즈)의 과거 성적표 — 판정별 승률·수익률과 설계 주장들의 진위  
📦 **자료** — 전 종목 과거 일봉, 리플레이 가능한 베이스 엔진, 설계 문서의 주장들(VCP는 응축 신호 / 단계 3+는 위험 구간 / 임계치 10%·15%), 동기간 지수 수익률  
🔗 **조건**
- 성적은 판정의 순간 하나마다 하나씩 매겨진다.
- 판정의 좋고 나쁨을 정하는 것은 절대 수익이 아니라 동기간 시장 대비다.
- M7의 착수 여부를 정하는 것은 이 성적표다.

#### 자료에서 미지까지

```text
📦 과거 일봉 전체
        │
        ▼
   ① 판정 이벤트        리플레이로 과거의 모든 판정(준비/성공/이탈) 순간 수집
        │ 🔗 판정 순간 하나마다 성적 하나
        ▼
   ② 전방 수익률        각 순간의 +5/20/60일 수익률 + 동기간 지수
        │ 🔗 좋고 나쁨은 시장 대비로 정해진다
        ▼
   ③ 가설 대조          VCP 유무별 성공률 / 준비의 실제 돌파율·거짓 경보율
        │                / 단계 3+의 변동성·낙폭 / 임계치 민감도
        ▼
   ④ 성적표             시그널별 승률·평균 수익 → 화면 노출("과거 성적: 승률 X%")
        │ 🔗 이 성적표가 M7 착수를 정한다
        ├─ 실패 → 기법(임계치·판정 로직) 수정 → ①부터 재시도
        ▼ 통과
🎯 "검증해봤어요?"에 숫자로 답할 수 있음 + M7 착수 자격
```

💀 **나쁜 성적도 손해가 아니다** — "이 방식이 옳지 않을 수도 있다"에 데이터로 답하게 된 것이고, 고칠 곳이 곧 다음 할 일 목록이다.

## M7. 평균회귀 렌즈 — 종목마다 맞는 기법으로 읽기 (착수 조건: M6 통과)

🎯 **미지** — 종목·시장마다 어느 기법으로 읽을지 정해져, 횡보장에도 침묵하지 않는 읽기  
📦 **자료** — 시장 판정(M4), 종목 리짐(횡보 구간 = 추세추종이 침묵하는 UNKNOWN), 기존 지지·저항 구조(박스 중심선), 검증 틀(M6), 기존 차트·카드 틀  
🔗 **조건**
- 두 기법의 관계는 경쟁이 아니라 구간의 분담이다 — 추세추종이 침묵하는 곳이 평균회귀의 자리다.
- 종목 하나마다 그 시점에 렌즈 하나가 정해진다.
- 기법이 바뀌어도 화면 틀은 같아야 한다.
- 이 렌즈도 M6과 같은 검증을 통과해야 한다.

#### 자료에서 미지까지

```text
📦 시장 판정 + 종목 리짐
        │ 🔗 종목 하나마다 그 시점에 렌즈 하나
        ▼
   ① 렌즈 선택          "이 종목은 지금 이 기법으로 읽는다"를 서비스가 결정
        ├─ 추세 구간 → 기존 읽기 (M1~M3)
        └─ 횡보 구간 → ② 회귀 읽기    평균과의 이격 · 과매도/과매수 · 회귀 목표가
        │                              (박스 중심선을 회귀 목표 후보로 재사용 검토)
        │ 🔗 기법이 바뀌어도 화면 틀은 같다
        ▼
   ③ 같은 틀 출력       같은 차트·같은 카드에서 판정과 해석문만 바뀜
        │ 🔗 이 렌즈도 같은 검증을 통과해야 한다
        ▼
   ④ 검증 반복          M6의 이벤트 스터디를 이 렌즈에도
        ▼
🎯 횡보 종목을 열어도 서비스가 침묵하지 않음 → 전체 미지의 마지막 성분(C) 완성
```

💀 **사용자에게 "모드 전환"으로 보이면 실패다** — "알아서 맞는 눈으로 읽어주는 것"이어야 혼합이 서비스가 된다.

## 대비쌍

- **M2 vs M1** — 숫자가 없으면 만들고(M2: 피벗·확장도), 있는데 안 읽히면 번역한다(M1: 해석문).
- **M3 vs M2** — 이미 계산된 것은 전달만(M3), 계산이 없던 것은 신설(M2).
- **좋은 종목 vs 좋은 자리** — 랭킹에 들어올 자격은 질(RS·FIP)이 정하고, 오늘 볼 순서는 거리(피벗 근접)가 정한다.
- **과정 채점 vs 결과 채점** — 단건은 과정(룰 준수)으로만 채점 가능하고, 결과(수익률)는 쌓여야 채점이 된다.
- **추세추종 vs 평균회귀** — 시장이 추세면 돌파로, 횡보면 회귀로 — 경쟁이 아니라 구간 분담.
